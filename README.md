# 降低英文ai率

一个用于检查和改写英文文章、脚本、邮件等文本的 Codex Skill。它着重处理空泛内容、机械句式、过度整齐的结构与缺少个人判断等问题，同时保留原意、事实和适合场景的文体。

“AI 率”是方便识别用途的名称；本 Skill 不计算 AI 生成概率，也不保证通过检测器。

## 安装

把本仓库作为 Skill 安装，或将仓库目录复制到 `~/.codex/skills/lower-english-ai-rate/`。入口文件是 [`SKILL.md`](SKILL.md)，原始英文指南保存在 [`references/article-en-dsv-v2.md`](references/article-en-dsv-v2.md)。

## 使用

- “用降低英文ai率检查这段英文，只指出问题，不改写。”
- “用降低英文ai率改写这篇英文文章，保留事实和引文。”
- “这份英文视频脚本不能改动原文，请列出修改建议。”

本仓库中的参考文章是用户提供的原稿；其中的研究、数据和外部链接应在正式引用前自行核实。
